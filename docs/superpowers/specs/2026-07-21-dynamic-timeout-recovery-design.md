# 动态瓶颈超时参与者恢复设计

## 目标

避免参与者一次决策超时后被永久限制为 1 秒页面停留并持续自动选择，同时不让无人操作的浏览器被误判为已经恢复。

## 行为

- 本轮决策超时后仍按既有规则随机补选，当前轮结果不可回改。
- 在 `Decision` 与 `ResultsSync` 之间增加 `RecoveryGate`。
- 活动掉线参与者进入该页后停止自动翻页，必须主动点击“重新加入实验”。
- 确认恢复后清除 `dropout_active` 和当前原因，但保留历史 `is_dropout`。
- 本轮继续展示自动补选结果；下一轮恢复完整决策时间。
- 记录本轮掉线事件、恢复原因和是否在本轮恢复，并导出。

## 边界

- 正常参与者不显示恢复页。
- 不增加心跳或 WebSocket 连接检测。
- 本次只修改 `dynamic_bottleneck_round`；`single_bottleneck` 后续可按同一机制同步。

## 验证

- 超时状态不会被页面加载自动清除。
- 只有确认恢复函数会清除活动状态。
- 历史掉线状态保持为真。
- 恢复页无计时器和自动跳转。
- 页面顺序为 `Decision -> RecoveryGate -> ResultsSync`。
