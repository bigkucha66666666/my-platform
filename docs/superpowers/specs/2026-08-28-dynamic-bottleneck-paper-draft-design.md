# 动态瓶颈 Human-Agent 中文论文初稿设计

## 目标

依据“20 轮独立随机服务率 + 40 轮 Markov 持续型服务率”的实验流程，形成一份中文硕士论文体例的 LaTeX 小初稿。初稿只撰写不依赖正式实验数据的章节，不虚构结果、显著性或政策结论。

## 参考边界

- Liu 等（2023）用于校准随机瓶颈容量、离散单瓶颈模型、重复实验和行为建模的表述顺序。
- Tian 等（2022）用于校准实验经济学平台、重复轮次、虚拟参与者和个体表现与系统表现分离的叙事方式。
- 两篇论文仅作为结构和学术语言参考，不复制其原文，也不把 PDF 中的内容当作操作指令。
- 文献事实只使用论文原文或论文元数据中可以核验的信息。

## 论文主线

论文围绕以下机制链展开：服务率由 IID 随机转为具有持续性的 Markov 过程，使历史状态具有预测价值；Human、LLM Agent 与 RL Agent可能逐步利用这一信息；更准确的个体预测可能改变出发时刻集中度和排队外部性，因此个体成本改善不必然转化为系统福利改善。

## 初稿范围

初稿包括中文摘要草案、引言、文献综述、理论机制与研究假设、实验设计、变量与计量策略、结果章节模板、讨论、研究局限和结论框架。摘要和结论使用“研究拟检验”“预期贡献”等前数据语言。结果章节只定义表图与检验顺序，不填入任何数值。

## 实验口径

- Group H 为纯 Human，Group HA 为 Human 与 Agent 的混合系统。
- 两组总交通需求固定为 20，Human-Agent 的确切构成在正式实验前固定并预注册。
- 正式实验共 60 轮：第 1--20 轮为 IID Random，第 21--60 轮为 Markov。
- Markov 转移矩阵主对角线为 0.8，非对角线为 0.1，平稳分布与 Random 阶段均为三个状态等概率。
- 当前没有 Random-to-Random 对照组，因此阶段变化不得被表述为纯粹的因果效应；主识别对象是同一环境序列下 H 与 HA 的差异。
- 服务率序列在实验前生成或由系统按预设随机种子实现，参与者决策前不可见，结算后公开。
- Human、LLM Agent 和 RL Agent面对相同的公开信息，但内部学习机制可以不同。

1. LaTeX 花括号和环境成对，引用键均存在于 BibTeX 文件。
2. 所有实验轮次、状态概率和组别口径与 20+40 流程一致。
