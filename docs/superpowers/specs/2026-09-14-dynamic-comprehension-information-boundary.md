# 动态瓶颈理解测试信息边界改造设计

## 范围

只修改 `dynamic_bottleneck_round` 场景的理解测试和热身轮数，不改动其他实验场景或问卷逻辑。允许同步该场景在 `settings.py` 中的管理员说明。

## 改造内容

1. 保留排队成本、早到成本和瓶颈服务率/到达时间三道题。
2. 删除与当前已停用粗收费不一致的第四题，替换为“同组同轮服务率一致性 + 决策前信息边界”题。
3. I0 条件的正确答案是：同组同轮服务率相同，决策前只知均匀分布范围，提交后才公布本轮精确值。
4. I1 条件的正确答案是：同组同轮服务率相同，决策前已知本轮精确值和容量等级。
5. 四题都作答并点击检查后即解锁下一页，不要求答案全部正确；服务端仅校验已完成全部题目和至少检查一次。
6. 按钮和反馈文案明确下一步是 3 轮练习，不是直接进入正式实验。
7. 保存最终得分、尝试次数和四题答案；在该场景自定义导出中附带得分和尝试次数。

## 验收标准

- I0 和 I1 的第四题正确答案不同，且由后端条件决定。
- 少选或未点击检查时不能通过服务端校验；错答在显示解释后可继续。
- 记录实际 0–4 得分和前端累计尝试次数，然后进入 3 轮练习。
- `dynamic_bottleneck_round` 的单元测试和 oTree bot 流程通过。
