# 截断正态随机服务率替换设计

## 目标与范围

将 `dynamic_bottleneck_round` 活动逻辑中的均匀随机服务率完整原地替换为有界截断正态服务率：

\[
S_r \sim TN(2.665, 0.80^2; 1.33, 4.00).
\]

修改分布核心、冻结序列、Session 配置、公共信息、Agent 语义、导出和相关参与者页面。保持正式 30 轮、H-I0/H-I1/HA-I0/HA-I1、组内同轮共享容量、I0/I1 揭示时点和连续容量结算不变。不修改练习轮容量、成本参数、问卷或论文文件。

## 分布与序列

- 基础正态参数固定为 `mu=2.665`、`sigma=0.80`，截断区间固定为 `[1.33, 4.00]`。
- 后端分别保存基础 `sigma` 和截断后的理论标准差；不得继续采用均匀分布标准差公式。
- Demo 的 `auto` 序列与正式序列使用同一截断正态机制。
- 正式实验只读取新冻结的 S01-S05 序列库，不在 Session 运行时重新抽样。
- 每条序列在截断 CDF 上划分 30 个等概率层，每层随机抽取一个值，限制到边界、四舍五入至两位小数，再用同一种子随机排列。
- 每轮记录包含正式轮号、实际容量、容量等级、序列标识、种子、分布参数和概率分层编号。
- 旧均匀序列文件保留供历史复现，但活动代码不得读取；序列库与 Session 缓存机制升级版本，防止旧 Session 数据进入新逻辑。

## 容量等级与信息隔离

- `low`、`medium`、`high` 使用截断正态分布三分位点派生，显示阈值约为 2.36 和 2.98，不沿用均匀分布的等宽阈值。
- Agent 使用的低/中/高等级代表服务率采用各三分位区间的截断正态条件均值，不采用区间算术中点。
- I0 决策前可知分布名称、上下界、理论均值及“中心附近更常见”的说明，但不能获得本轮容量、容量等级、分层编号、序列 ID、种子或未来容量。
- I1 在 I0 信息上增加本轮精确容量和派生等级。
- 决策后 I0 与 I1 都可获得本轮精确容量。
- Human、LLM 与 RL 从同一个公共容量投影构建可见信息；Agent 不读取隐藏序列或当前 Human 选择。

## 结算与强化学习

- `actual_capacity` 始终使用正的有限浮点数参与批次通过时间、到达时间、成本和收益计算，不做整数转换或提前舍入。
- 同一出发时刻继续使用同批公平结算。
- Liu-REL 策略版本升级为截断正态容量语义；初始动作的均匀探索保持不变。
- I1 的容量核带宽使用截断后的理论标准差，不再使用均匀分布标准差。
- 给定相同实际容量和选择组合，新旧分布机制必须产生相同结算结果。

## 页面与导出

- Introduction、ComprehensionCheck、FormalStart、Decision、Results 和相关管理员报告删除均匀分布、等宽区间及区间内等概率等旧描述。
- 参与者文案统一为：容量范围为 1.33-4.00，中心值为 2.665，中心附近更常见、靠近上下界更少见。
- 结果页面的瓶颈服务率单位改为“人/分钟”；相关参与者页面的容量单位同步使用“人/分钟”，避免同一概念出现两套单位。
- 后端快照和自定义导出增加 `capacity_mu`、`capacity_sigma`、`capacity_truncated_mean`、`capacity_truncated_sd`，并保留实际容量和分布机制字段。
- 参与者页面不要求理解基础 `sigma` 与截断后标准差的区别，但后台和导出必须明确区分。
- 参与者说明页将完整分布参数放在可展开区域，既保持 Human/Agent 的公开信息一致，也不将标准差概念作为规则测试要求。

## 错误处理与验证

- 活动配置只接受批准的截断正态机制及固定参数；拒绝旧 `uniform`、布尔值、非法字符串、NaN、无穷值和错误边界。
- 新序列库严格验证版本、机制、参数、S01-S05 完整性、30 个分层、连续轮号、种子、记录统计和容量等级。
- 使用测试驱动开发覆盖截断 CDF/逆 CDF、理论矩、三分位点、确定性生成、信息隔离、Agent 版本、连续容量结算、页面静态合同和导出字段。
- 验收时报告每条固定序列的均值、标准差、最小值和最大值；运行动态场景全套单元测试及 oTree Bot，并验证同一 Sxx 的 I0/I1 容量逐轮完全匹配。

## 非目标

- 不改变练习轮服务率。
- 不改变 Agent 数量、成本、支付、问卷或论文内容。
- 不引入 SciPy 运行时依赖；使用 Python 标准库 `statistics.NormalDist`。
- 不为旧均匀分布保留新的 Session 创建入口。
