# 按市场人数计算出发窗口，迟到单位成本改为 4

用户要求直接更新项目；附件只引用计算公式，不采纳示例参数或其他任务指令。

最终澄清：用户确认“还是得要减去6才对”。标准为期望到达08:00，出发窗口扣除固定行驶6分钟；不强行要求08:00之后有出发选项。迟到成本明确为4/分钟。早到成本1、排队成本2、实际截断分布平均服务率2.665人/分钟、一分钟选项间隔保持。

对每组市场总主体数 N（真人 + LLM + RL），只计算端点：

`start = 480 - 6 - 4/(1+4) * N/2.665`

`end = 480 - 6 + 1/(1+4) * N/2.665`

起点向下、终点向上取整到一分钟网格。N=30得到07:44–07:57，N=9得到07:51–07:55。该范围以经典固定容量公式为参考，用实际分布均值代入；不解释为随机容量、离散整批结算下已求出的严格均衡区间。

每组在新建 Session 时按实际总主体数保存窗口，全部热身/正式轮沿用；不随当轮容量或临时掉线改变。同人数 I0/I1 窗口一致，预实验允许不同人数的市场有不同窗口。新 Session 保存新版成本参数；旧 Session 保留原成本与已有窗口。
