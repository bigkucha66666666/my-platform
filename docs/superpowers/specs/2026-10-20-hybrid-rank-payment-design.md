# 正式报酬：成本与排名混合，最高 30 元

用户选择成本占80%、排名占20%的混合方案，并将最高总报酬提高到30元。基础15元，成本奖金0–12元，排名奖金0–3元。新版本 dynamic_cost_rank_v3 仅成为新正式 Session 的默认值；历史 v1/v2 公式保持原样。

正式30轮平均成本 C，组内人数 N 包含真人、LLM、RL。沿用累计成本六位小数比较和竞赛排名 r，若 t 人并列，奖金平均名次 m=r+(t-1)/2。N>1时排名得分 p=(N-m)/(N-1)；单人无竞争，p=0.5。成本奖金=max(0,12-0.3C)，排名奖金=3p。各项奖金四舍五入至分后相加；总报酬15–30元。所有人并列时排名奖金均为1.50元。Agent不领取现金，其虚拟奖金不重分配给真人。自动代选继续计入成本，不新增资格处罚。

支付必须同时具备正式30轮完整成本及第33原始轮的私人排名快照，快照规则、轮数及个人总成本必须一致；缺失或不一致转人工核验，不用未完成轮次或默认第一名计算。结算幂等，并使oTree原生金额、收据及导出一致。基础费仍15元，每实验会计积分0.01元；排名不改变原始出行成本和实验积分。

最终收据披露平均成本、最终名次（含Agent）、平均名次、成本奖金与排名奖金。正式开始前披露同一公式、并列办法及人数口径。每轮结果排名为进度，最终30轮才计奖。80名真人的保守最高报酬预算为2400元，不含API费用，不沿用旧2000元限额。

用户进一步确认保留Agent成本最小化目标，仅修改真人报酬；LLM提示词、RL学习收益和训练经验保持原样。这是固定策略比较基准，真人和Agent的激励设置不同，不能据此宣称完全相同的奖金目标。所有验收使用临时数据库和模拟API，无线上部署或历史数据重算。
