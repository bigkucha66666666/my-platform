# 成本与排名混合奖励：最高30元

## 最终规则

用户选择原推荐的成本80%＋排名20%方案，并把最高报酬提高到30元。保留基础15元，将绩效15元拆成成本奖金最高12元和排名奖金最高3元。新版本名为 `dynamic_cost_rank_v3`，只成为新正式场次的默认值。

设正式30轮总成本为 S，平均成本 C=S/30。本组实际配置的全部主体数为 N（真人＋LLM＋RL），最终累计成本显示名次为 r，并列人数为 t，计奖平均名次 m=r+(t−1)/2。

\[
B_{cost}=\max(0,12-0.3C),\quad
B_{rank}=3\frac{N-m}{N-1},\quad
R=15+B_{cost}+B_{rank}.
\]

两项奖金分别按四舍五入保留到人民币分，再相加。程序直接计算成本奖金的分数 `max(0,1200-S)`，避免 `S/30` 的循环小数影响恰好半分的舍入。

- 无并列时，第一名排名奖金3元，最后一名0元，中间按相对名次线性分配。
- 并列者分享占用名次对应的奖金。例如9人组并列第2、3名，平均名次2.5，排名奖金为 `3×(9−2.5)/8=2.4375` 元，支付2.44元。
- 所有人并列时每人排名奖金1.50元。单人无竞争时同样采用中性1.50元，已写入实验说明。
- 排名沿用既有口径：累计正式成本保留六位小数比较，成本越低越靠前；不使用页面显示的四位平均成本重新排名。
- 热身轮不计入；第30轮正式实验结束才确定奖金，每轮累计排名只是进度。
- N使用本组Session创建时保存的主体数，自动代选仍占一个主体并计入成本，不随掉线减少。
- 用户明确确认Agent继续以自身成本为目标，不领取现金，不将其虚拟排名奖金重新分配给真人。LLM提示词、RL学习目标和经验库没有因本次支付修改而改变。真人与Agent的激励设置存在差异，研究解释应如实说明。

### 计算示例

下表是公式示例，不是实际预实验支付结果。9人组，正式平均成本为20，成本奖金为 `12−0.3×20=6` 元。

| 最终位置 | 排名奖金 | 总报酬 |
| --- | ---: | ---: |
| 第1名，无并列 | 3.00元 | 24.00元 |
| 第5名，无并列 | 1.50元 | 22.50元 |
| 第9名，无并列 | 0.00元 | 21.00元 |
| 并列第2、3名 | 2.44元 | 23.44元 |

总体报酬范围15–30元；平均成本为0且独占第一名时达到30元。80名真人的保守最高报酬预算为2400元，不含API支出，不再使用旧2000元预算描述。
