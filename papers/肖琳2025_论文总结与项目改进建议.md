# 肖琳 (2025) 论文总结与项目改进建议

> 论文：**智能网联环境下基于奖励的交通需求管理方案优化**
> 作者：肖琳，同济大学博士论文，2025年7月
> 指导教师：孙剑 教授

---

## 一、论文核心概要

### 1.1 研究问题

在智能网联汽车（CAVs）与传统人工驾驶车辆（HVs）共存的交通环境中，仅调控CAVs可使系统趋近最优状态，但会导致部分个体效用受损（非帕累托最优）。论文聚焦于**基于奖励的交通需求管理（IBTDM）** 策略，通过经济奖励补偿利益受损个体，以充分发挥CAVs缓解拥堵的潜力。

### 1.2 主体分类框架

论文将出行者按两个维度分为四类，最终归并为三类研究：

| 维度 | 理性 | 非理性 |
|------|------|--------|
| **CAVs** | 理性CAVs（完全信息下与理性HVs行为逻辑相同，归并研究） | 非理性CAVs（不完全信息，群体通信+推理+协同优化） |
| **HVs** | 理性HVs → 与理性CAVs归并 | 非理性HVs（有限理性，锚定效应、损失规避、启发式选择） |

### 1.3 三大研究内容

1. **理性主体建模与奖励推导**（第3章）：基于Vickrey瓶颈模型，解析理性CAVs/HVs在奖励下的出发时间选择，求解预算分配（宣传成本 vs 激励成本）和最优时变奖励方案。

2. **非理性HVs行为建模**（第4章）：问卷调查（高德地图，苏州）+ 31天长时交互实验，采用Transformer构建出发时间选择预测模型（准确度比LSTM/NN提升35%+）。

3. **异质主体仿真与奖励优化**（第5章）：构建三类Agent仿真平台，采用智能增强（IA）方法融合专家经验与贝叶斯优化，实现基于主体类型的差异化奖励方案。

## 二、核心发现与方法论要点

### 2.1 理性假设下的最优奖励

- **最优时变奖励呈"V型"或"U型"**：高峰中心奖励最低（甚至为0），远离高峰时段奖励升高。与最优收费方案呈"镜像"关系。
- **预算配置**：宣传资源应优先配置给单位宣传成本更低的CAVs群体。最优渗透率不会随总预算严格提高。
- **关键参数**：单位出发时间偏移成本 θ 与单位行驶时间成本 α 的相对大小决定最优奖励形式。

### 2.2 非理性HVs行为特征

- **影响因素**：月收入、年龄、教育程度、驾照持有状态、通勤频率、实验机制理解程度。
- **奖励接受度关键因素**：公共交通倾向性、月收入、出行天数（出发时间调整策略）；公共交通倾向性、私家车保有量、OD组合特征（出行方式转换策略）。
- **行为演化**：非理性HVs具有"中期偏好"和较强惯性，出发时间调整幅度小，需强刺激+即时反馈。

### 2.3 仿真优化核心结果

| 指标 | 理性假设方案 | 优化方案 | 改善幅度 |
|------|:-----------:|:------:|:-------:|
| 系统总延误 | 3346 分钟 | 1107 分钟 | **-67%** |
| 较无奖励基准 | -22% | -74.3% | — |
| 预算投入 | 3612 元/轮 | 2012 元/轮 | -44% |
| 投资回报率（ROI） | 0.27 分钟/元 | 1.59 分钟/元 | **+5倍** |

### 2.4 差异化奖励策略

- **理性主体**：奖励集中于高峰后段，高强度快衰减。
- **非理性HVs**：奖励集中于高峰前中段，长持续缓衰减，峰值金额高。
- **非理性CAVs**：奖励高峰后移，长持续。
- **预算受限时**：奖励资源向非理性HVs倾斜（预算占比从17%升至30.3%），削减非理性CAVs预算。

### 2.5 实验设计方法学亮点

- **长时追踪机制**：31天实验（10天对照+21天干预），以"天"为选择周期。
- **防样本流失**：缺席轮次成本205元（最大成本值），阶梯式奖励扣减（缺席2天扣5%，3天扣25%），累计排名奖励。
- **Behavioral data quality**: 天为单位避免思考时间不足导致的行为失真。

## 四、具体改进建议

### 建议1：引入出行者异质性参数

**现状**：所有参与者共享 `QUEUE_COST_PER_MINUTE=2`、`EARLY_COST_PER_MINUTE=1`、`LATE_COST_PER_MINUTE=3`。

**改进**：在 session config 中添加异质性参数，支持多种"出行者类型"。

```python
# 新增 session config
HETEROGENEITY_ENABLED = 1
# 出行者类型比例: 理性:非理性HV:非理性CAV
AGENT_TYPE_RATIOS = '0.4,0.4,0.2'
# 各类型成本参数（可设不同VOT）
ALPHA_TYPES = '2.0,1.5,2.5'  # 排队成本
BETA_TYPES = '1.0,0.8,1.2'   # 早到成本
GAMMA_TYPES = '3.0,4.0,2.5'  # 晚到成本
```

参与者在进入实验时被随机分配类型标签，不同类型看到不同的成本结构。

### 建议2：将固定轮次升级为可配置的长时实验

**现状**：`NUM_ROUNDS = 10` 写死。

**改进**：
- 使 `NUM_ROUNDS` 可配置（如 30 轮），对标论文的31天实验。
- 添加"无奖励对照期"：前 N 轮关闭奖励，后 M 轮开启。
- 实现论文中的防流失机制：缺席成本惩罚、累计排名奖励。

```python
# 新增配置
NUM_ROUNDS = 30  # 可从 session config 读取
BASELINE_ROUNDS = 10  # 前10轮无奖励对照
REWARD_ROUNDS = 20    # 后20轮奖励干预
ABSENCE_COST = 50     # 缺席轮次固定成本
RANKING_BONUS_ENABLED = 1  # 累计排名奖励
```

### 建议3：奖励方案从"固定时点固定金额"升级为"时变曲线"

**现状**：`rewarded_slot_spec = '1-3,9-11'` + 固定 `reward_bonus_points`，本质是均匀奖励。

**改进**：支持时变奖励曲线，参考论文的RBF（径向基函数）参数化方法：

```python
# 时变奖励参数（RBF形式）
REWARD_TYPE = 'time_varying'  # 'fixed' | 'time_varying'
# 每个RBF分量: (中心时刻, 幅值, 宽度)
# 例如: 在 7:45 峰值为 40 分, 8:30 峰值为 25 分
REWARD_RBF_PARAMS = '07:45,40,15|08:30,25,20'
```

这样可以在实验中测试论文中的"V型""U型"奖励形状。

### 建议4：实验组间对比设计（Treatment对比）

**现状**：单一场次配置，缺乏对照组。

**改进**：在 `settings.py` 中添加多套 SESSION_CONFIG 以支持 A/B 测试：

```python
# 对照组：无奖励
'single_bottleneck_control': dict(
    reward_treatment_enabled=0,
    ...
),
# 实验组1：理性假设最优奖励（V型）
'single_bottleneck_treatment_v_shape': dict(
    reward_treatment_enabled=1,
    REWARD_TYPE='time_varying',
    REWARD_RBF_PARAMS='07:44,50,5|08:04,50,5',  # 两端高
    ...
),
# 实验组2：基于主体类型的差异化奖励
'single_bottleneck_treatment_diff': dict(
    AGENT_TYPE_RATIOS='0.4,0.4,0.2',
    REWARD_BY_TYPE_ENABLED=1,
    ...
),
```

### 建议5：添加"预算约束"与"渗透率"概念

**现状**：奖励无预算限制，所有参与者都能看到奖励。

**改进**：
- 添加全局预算约束参数 `TOTAL_REWARD_BUDGET`（每轮奖励总额上限）。
- 引入"渗透率"概念：预算决定了可覆盖用户比例。
- 当奖励需求超过预算时，系统自动按规则缩减或分配。

```python
TOTAL_REWARD_BUDGET = 200  # 每轮奖励总预算上限
BUDGET_ALLOCATION_MODE = 'proportional'  # 'proportional' | 'priority'
```

### 建议6：数据采集与分析增强

**现状**：导出出发时点、延迟、成本等基础数据。

**改进**（对标论文第4章的分析方法）：
- 添加面板数据分析导出（个体 x 轮次矩阵格式）。
- 在 admin report 添加行为聚类可视化（K-means，识别"早鸟型""跟风型""惯性型"参与者）。
- 添加"策略接受度"指标：实际选择受奖励时点的比例。

### 建议7：非理性行为诱导机制

**现状**：参与者完全自主选择，无行为干预。

**改进**（对标论文实验设计）：
- 在结果页增加"历史选择对比"：显示参与者自身 vs 组平均的偏离程度。
- 在决策页增加"推荐出发时间"提示（模拟CAVs的路径推荐功能）。
- 引入"信息不完全"处理：某些轮次隐藏他人的出发时间分布。
